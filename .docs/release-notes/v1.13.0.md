## Release v1.13.0
*Released at 2026-10-01T05:40:00.976Z*

> Event Horizon can now measure itself: a built-in benchmark suite runs seeded tickets end to end and scores agent friction, cost and outcomes. Alongside it come a new Antigravity (`agy`) runtime, Oneshot groom-and-build sessions, live capacity and compaction tracking, and a data-safety sweep that stops EH from ever stashing your dirty main tree or silently losing a ticket write.

### Highlights

**Benchmark suite.** The FLUX-1739 epic adds a full benchmark harness: a seed registry and a New benchmark panel, suites that dispatch seeded tickets through real agent sessions, a results screen with cross-seed comparison and per-run work metrics, a regression check, and a Benchmark Analyst persona. Friction is re-derivable — end-of-run ticket state is frozen and recomputed on rebuild — and harness failures count as attrition rather than verdicts. A build track lets seeds declare playable artefacts (screenshots and the built product are kept and served in a gallery), and every run records the engine commit and agent CLI version (FLUX-1759). Running it against EH itself fed straight back into the product: the Ready hand-off now counts as a done signal (FLUX-1760), a turn that ends in a working status is no longer treated as handed off (FLUX-1761), progress entries name the command being run (FLUX-1763), and the implementation prompt right-sizes the check gate instead of paying for the full suite on one-file fixes (FLUX-1762).

**More runtimes, more ways to run them.** The Antigravity CLI (`agy`) joins as a first-class runtime adapter, with prompt-delivery guards for empty prompts, no-op turns and quota classification; gemini moves to legacy/enterprise (FLUX-1738). **Oneshot** grooms and implements small tickets in a single session (FLUX-1733), each task chat gets its own CLI picker in the chat header (FLUX-1706), and the review phase gains a slop-auditor persona plus a finite-testability checklist (FLUX-1740). MCP structured results are now mirrored into `content[]`, which unblocks every non-Claude-lineage client (FLUX-1721); the Copilot integration is refreshed; Grok's orchestrator skill path is fixed (FLUX-1726); and skill staleness detects edits to any module, not only the orchestrator (FLUX-1749).

**Capacity and compaction awareness.** Sessions now capture `rate_limit_event` and `compact_boundary` (FLUX-1744). Codex and Copilot get capacity probes behind `GET /api/usage` and a `usageChanged` SSE channel (FLUX-1747), and the portal adds a capacity popover, settings panel and session context strip (FLUX-1748). Furnace's resume gate no longer inverts around compaction (FLUX-1745), and sessions checkpoint before the context cliff so dropped tokens show up on the hand-off (FLUX-1746).

**Your git tree and your tickets are safe.** Merge-cleanup sync never stashes the user's dirty main tree again (FLUX-1770), and neither does reconciling a PR closed unmerged (FLUX-1782); worktree lookups no longer match the main tree (FLUX-1776). Worktrees made by `branch create` are protected from reclaim while a non-EH session is using them (FLUX-1771, FLUX-1778). On the ticket side, `create_ticket` can no longer report success for a file that never persisted (FLUX-1634), concurrent creates can't receive the same id (FLUX-1756), a partial read never overwrites the cached ticket (FLUX-1754), and the watcher stops evicting tickets on every rename-replace write. The docs viewer's rich-text editor no longer corrupts markdown on save (FLUX-1719).

**Workflow and multi-board polish.** Commits that land on the default branch with a `Closes:`/`Fixes:`/`Resolves:` trailer close their tickets (FLUX-1773, FLUX-1779). `start_session` confirms the dispatched session actually started (FLUX-1772), `ask_user_question` uses MCP elicitation, or fails fast, when no portal is watching (FLUX-1774), and board health flags In Progress tickets with no session for 48h (FLUX-1775). The new `bind_workspace` tool, with registered boards auto-opened and persisted, no longer drops back to the default board mid-session (FLUX-1781), and the portal switcher tracks boards opened by agents. Furnace/gate stops are attributed correctly instead of "stopped by user" (FLUX-1623), and sync-skip notifications are no longer suppressed forever (FLUX-1777).

**Linux and CI.** Linux gets deb, rpm and pacman installers alongside the AppImage (FLUX-1712), and GUI launches resolve the user's login-shell PATH so agent CLIs are found (FLUX-1711). CI moved to a self-hosted runner, and cards and PRs show whether hosted or self-hosted CI verified a ticket (FLUX-1713). A fresh, unbound engine no longer spams Unhandled Rejection every stoke tick (FLUX-1710).
