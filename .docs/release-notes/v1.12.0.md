## Release v1.12.0
*Released at 2026-08-22T07:59:45.934Z*

> Event Horizon goes cross-platform for real: Linux joins macOS and Windows with a standalone binary and an AppImage desktop installer. Around it, the knowledge-ops epic lands docs-as-code first-class support, onboarding gains a guided GitHub CLI step, and a pre-release Furnace sweep closed out twenty-odd reliability and polish bugs.

### Highlights

**Linux support.** The release pipeline now ships a standalone Linux binary (`event-horizon-linux-<version>.zip`, same self-contained single-file model as macOS) and an Electron **AppImage** desktop installer, both built natively on Linux CI (FLUX-1694). Landing this surfaced — and fixed — a real ship-blocker: the packaged engine exited silently right after boot on any Linux host without a system tray (headless boxes, stock GNOME), because the tray helper's exit unconditionally took the engine down. Tray-exit now only means "Quit" when the tray actually came up.

**Knowledge-ops: docs are first-class now.** The FLUX-1652 epic makes EH a real home for docs-as-code repos: git-backed doc revision history with rendered previews in PR diffs (FLUX-1653), a docs editor that round-trips markdown faithfully (FLUX-1654) and no longer drops front-matter on save (FLUX-1650), viewer save-as-revision with a publish message (FLUX-1655), fidelity-safe rendered editing via block-scoped source splicing (FLUX-1663), Mermaid rendering in the viewer and recaps (FLUX-1674), and a rendered-first viewer with git-derived provenance (FLUX-1672). Docs-touching branches now auto-emit a styled, tabbed **doc recap** artifact on the ticket surface (FLUX-1662, FLUX-1667, FLUX-1669), the PR card itself shows the branch diff plus a PR-scoped recap (FLUX-1670, FLUX-1676), and a docs-viewer state overhaul closed a Save-as-data-loss vector (FLUX-1671, FLUX-1660). External systems get a connectors settings panel with live auth probes (FLUX-1656) and per-connector read/write scoping for agent sessions (FLUX-1657, FLUX-1659).

**Onboarding that sets you up to ship.** A dedicated GitHub CLI install + auth step with live re-check joins onboarding (FLUX-1683), per-step skips mean "Skip setup" can't silently bypass it (FLUX-1684), and gh availability now self-heals with periodic re-probes instead of a boot-frozen flag (FLUX-1686). The sweep also fixed the step's failure surfacing (FLUX-1687, FLUX-1692), the launch-dialog status flash (FLUX-1693), the "Open the docs" CTA abandoning setup (FLUX-1688), and `mandatory` not actually being enforced on path-setup (FLUX-1689).

**Session and multi-workspace reliability.** Phantom "active" sessions are gone: stale waiting-input stubs no longer inflate board state, resurrect across restarts, bleed between boards, or pin worktrees (FLUX-1636, FLUX-1642). Worktrees branch off origin/master so stray local commits can't ride into unrelated PRs (FLUX-1638), Stop controls respond immediately across portal surfaces (FLUX-1680), Codex tickets no longer stall after a review requests changes (FLUX-1681), and quota-exhausted sessions surface a terminal diagnosis in the portal (FLUX-1640). Multi-workspace guardrails part 2 adds agent-403 on switch plus index-safe open/switch (FLUX-1678), mutating REST calls that name an unloaded workspace are refused (FLUX-1675), and MCP sessions get workspace-binding disclosure plus a read-only `list_workspaces` tool (FLUX-1573).

**Faster gates, honest CI.** The engine test suite is tiered into a fast thread-pooled unit project and a forked integration project, with the local `check` gate running only tests related to what actually changed — 55-96% faster per ticket (FLUX-1665). This release also repaired the gate itself: a Vitest 4 `groupOrder` crash had broken `vitest related` entirely (FLUX-1690), and git fixtures now set a hermetic local identity so the suite passes on machines and runners with no global git config (FLUX-1679). Ticket payloads got lighter too — terminal CLI sessions no longer ship megabytes of liveOutput in ticket detail (FLUX-1685).

**Hardening.** The doc-recap HTML sanitizer went through two rounds: unquoted inline event handlers stripped (FLUX-1666), then quote-aware tag boundaries, the `xlink:href` sink, and `data:image` allowances (FLUX-1699). Copilot sessions get a resolver-aware binary precheck everywhere instead of raw `spawn ENOENT` (FLUX-1641, FLUX-1700), and `flux:release` keeps the electron lockfile version in step (FLUX-1622, FLUX-1698).
