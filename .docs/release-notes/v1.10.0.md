## Release v1.10.0
*Released at 2026-07-31T06:32:28.307Z*

Changes since v1.9.1:

### Features

- **FLUX-1616** (#690): One-click global MCP install — a settings button installs the event-horizon MCP server into the global MCP settings of whichever CLI/tool is connected (Claude Code, Gemini CLI, …), so every project sees the board without per-repo setup.

### Fixes & improvements

- **FLUX-1613** (#689): Plan feedback sent while the reviewer is mid-turn no longer vanishes silently — it is visibly queued in the UI, and an in-flight plan-review pass is interrupted so mid-review feedback takes effect immediately instead of being reviewed against a stale plan.
- **FLUX-1617** (#691): Worktree reclaim hardening — self-heals when a reclaimed worktree's path must be recreated, relaxes stale-session detection so live sessions aren't evicted, and names the reclaim holder for clearer diagnostics.
- **FLUX-1619** (#692): Nav and chat-dock buttons no longer grow sideways on hover, ending layout shift that made quick navigation clicks miss.

### Housekeeping

- This release's ticket sweep also retro-moved the v1.8.x–v1.9.x Done backlog to Released (the v1.9.0/v1.9.1 notes were hand-written and never ran the sweep). The full swept-ticket list is in `INDEX.md` under this release's block.
