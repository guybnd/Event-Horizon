## Release v1.11.0
*Released at 2026-08-05T01:48:35.474Z*

> A big one: Codex CLI lands as the fourth runtime framework, sync gains hard data-loss protection at every reset seam, Windows worktree teardown stops eating sessions, and the Axis Mundi design system ships as the new face of the portal.

### Highlights

**Codex CLI adapter — fourth runtime framework.** OpenAI's Codex CLI joins Claude Code, Gemini, and Copilot as a fully-supported agent runtime (FLUX-1625), hardened by a rapid fix train: real model ids and effort declarations (FLUX-1629), chat turns rendering in chat instead of as ticket comments (FLUX-1630), mutating event-horizon MCP calls working under the sandbox (FLUX-1631), scatter + background capabilities live-probed and enabled (FLUX-1633), and codex event shapes understood by the chat projection (FLUX-1637). Adapter authors also get CAPABILITY_PROBES, an in-code verification checklist (FLUX-1626).

**Sync that can no longer lose your work.** The multi-writer flux-data epic (FLUX-1258) replaces textual merge with push-as-CAS + idempotent command replay, and FLUX-1643 closes the remaining data-loss seams: every CAS reset and force-reset now snapshots distinct HEAD/index/worktree/untracked bytes per sidecar path into an external recovery manifest before any `reset --hard`, journal acknowledgement is exact-prefix, artifact publication is serialized, and the portal shows a durable recovery path.

**Windows worktree resilience.** Session starts no longer die on leftover worktree "husks" — an unrepairable directory now routes to a suffixed recovery worktree while sweeps dispose of the husk in the background (FLUX-1644, plus the reclaim-gap fixes of FLUX-1617). And agents can now declare TTL-bounded holds on background processes (FLUX-1645), so a long Gradle-style build survives a session pause instead of being tree-killed mid-flight.

**Multi-workspace, for real.** The run-multiple-workspaces epic (FLUX-1230) lands: per-workspace board/Furnace chats that stay put when you switch (FLUX-1576), PR cards created in their owning board's store rather than the ambient one (FLUX-1579), and workspace-scoped session routing throughout.

**Axis Mundi design system.** New Axis Night + Axis Day themes with full token coverage, the lapidary Cinzel display type, and the axis mark across exe/installer/tray/favicon (FLUX-1588, FLUX-1589, FLUX-1593); Axis Day is the default for new installs (FLUX-1602), the new-ticket screen is redesigned (FLUX-1592), and hover-growing buttons stopped jiggling the nav (FLUX-1619).

**Auth failures now diagnose themselves.** CLI auth failures abort fast instead of riding out ten retries (FLUX-1598), the engine detects binary divergence and settings shadowing itself (FLUX-1599), resolves the `claude` binary via the login shell on macOS (FLUX-1600), and chat shows an actionable auth-error card that auto-recovers once you re-login — no app restart (FLUX-1601). Fresh installs no longer wedge on a silent hung spawn (FLUX-1596).

**Leaner grooming, unwedged plan gate.** The plan-pipeline epic (FLUX-1586) ships compressed grooming rules (FLUX-1582), revise-as-if-right-the-first-time revision focus (FLUX-1583), oversize-body lint feeding reviewer standing (FLUX-1584), a plan gate that keys re-review on body-hash change instead of stalling (FLUX-1585), and queued-feedback visibility for mid-turn plan feedback (FLUX-1613). Dispatched sessions advance to Ready/Done autonomously again (FLUX-1590), and a one-click button installs the event-horizon MCP server into whatever CLI is connected (FLUX-1616).
